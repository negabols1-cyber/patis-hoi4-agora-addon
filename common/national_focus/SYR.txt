# Syria (SYR) national focus tree
#
# Layout (x columns):
#   0-4    Economy (SYR_the_mandate_economy)
#   7-11   Loyalist route: stay with France (SYR_ratify_the_franco_syrian_treaty)
#   13-17  Opening trunk (SYR_the_general_strike)
#   16-26  Independence trunk and the three ideology branches
#          (communist x16-18, fascist x20-22, Hashemite monarchy x24-26)
#   28-30  Military (SYR_an_army_for_syria)
#
# The loyalist and independence routes split at SYR_crossroads_of_the_levant.
# The independence route runs on the National Resistance meter
# (SYR_resistance, decisions in common/decisions/SYR.txt). The leadership
# event syria.40 sets SYR_route_communist, SYR_route_fascist or
# SYR_route_monarchy, which opens one ideology branch.
# Helpers: common/scripted_effects/SYR_scripted_effects.txt,
#          common/scripted_triggers/SYR_scripted_triggers.txt
# Design notes: docs/systems/syria_focus_tree.md
###########################################################################
